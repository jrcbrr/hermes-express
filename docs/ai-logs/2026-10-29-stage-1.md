     Stage 1 — Design system & landing page

     Context

     Stage 0 left a placeholder home page using shadcn's default grey tokens and
     Geist fonts. Stage 1 (PLAN.md §3, §4, §12) adds the Hermes Express look:
     brand tokens (light + dark), fonts, logo/mascot/favicon, the site chrome
     (header, mobile bottom tabs, footer), a sound-toggle stub, and the full
     landing page. All later stages build on these.

     Decision (confirmed): light-mode primary-foreground becomes espresso
     #2B1E17, not white. White on #B8892E is about 3.1:1 and fails AA; espresso
     is about 5.0:1. Gold is never used as small text on cream. Links use Aegean
     blue. PLAN.md §3 table is updated to match.

     Branch

     git checkout -b stage-1-design from main (clean).

     New dependencies

     - next-themes: light/dark toggle, as required by the stack. Only new 
       runtime dependency.
     - Not adding Motion yet. The hero cup fill and builder teaser are plain CSS
       keyframes on SVG. They render on the server, ship no extra JS, and are
       easy to switch off with prefers-reduced-motion. Motion arrives in Stage 4
       for the real pour/stack/mix.

       surface, surface-muted, foreground, primary, primary-foreground, accent,

     3. Brand art: src/components/brand/

       src/app/apple-icon.tsx (ImageResponse, 180×180, cream background, gold
       mark). I'll check the metadata/app-icons doc first.

     4. Theme and sound

     - src/components/theme/theme-toggle.tsx (client): a button that switches
       between light and dark using resolvedTheme. The Sun and Moon icons swap
       with dark: classes and the label stays fixed ("Toggle dark mode"), so
       there is no hydration mismatch.
     - src/hooks/use-sound.ts (client): useSound() returns { muted, toggleMuted,
       play }. Mute is stored in localStorage under hx-sound-muted and read
       with useSyncExternalStore (SSR-safe, synced across tabs). Sound is on by
       default. play(name) does nothing until Stage 8.
     - src/components/sound/sound-toggle.tsx: a Volume2/VolumeX icon button with
       aria-pressed and the label "Mute sounds" or "Unmute sounds".

     5. Navigation: src/components/layout/

     6. Formatting helpers: src/lib/format.ts

     - Both have full unit tests (90% gate).
